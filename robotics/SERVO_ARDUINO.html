Definition • 1

What is a Servo Motor?

  • A servo motor is a rotary actuator
  • It allows precise control of angular position
  • Most hobby servos turn from 0° to 180°
Angle90°

Drag the slider and move the horn!

Definition • 2

Two Kinds of Servo

Open Loop

Continuous rotation servo. No position feedback: you set speed and direction, it just spins.

Closed Loop

Standard servo. A sensor reports the real angle back, so it stops exactly where you tell it. This is the one we use!

Definition • 3

What Does "5 kg" Mean?

✕

NOT how heavy the motor is

✓

How strong it turns (torque), rated in kg·cm

Hardware

Servo Motor Pinout

GND

common ground

5V

positive voltage

CTRL

input for the control system

3 pins only! Wire colors can vary:
brown/black = GND • red = 5V • orange/yellow = CTRL

Wiring

Connect the 3 Wires

CTRL → digital pin 9
(any digital pin works)

Small servos (like the 9 g one) can use the Arduino 5V. Big servos need an external supply, with the GND shared.

Code • Part 1

Library & Servo Object

#include <Servo.h>

Servo servoA;

#include

Tells the Arduino to use commands from a pre-made library.

Servo.h

The library that knows how to drive servo motors.

Servo

Creates a servo object (one for each servo).

servoA

Our servo's name. You choose it! We use servoA. next.

Code • Part 2

attach(pin)

servoA.attach(9);
  • Links the servo to a pin
  • The number is the digital pin the CTRL wire is plugged into
  • Put it inside setup()

👆 Tap the pin your CTRL wire uses:

CTRL wire ➜ pin 9

The number in attach() must match your wiring!

Code • Part 3

write(angle)

servoA.write(90);
  • Moves the servo to the angle
  • Valid angles: 0 to 180
  • 90 = the middle
Angle
190 ✗ out of range!
