Definition • 2

What is an LCD I2C?

Photo: ArduinoGetStarted.com
  • I2C = a 2-wire serial bus: SDA carries data, SCL carries the clock
  • A small backpack board (usually a PCF8574 chip) is soldered onto the LCD
  • Each I2C device has an address like 0x27

Code • Part 1

Library & LCD Object

#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

#include

Loads the library that knows how to talk to the LCD.

0x27

The I2C address. Some modules use 0x3F.

16, 2

Columns and rows of the screen.

lcd

Our LCD object name. We call its functions with lcd.

Code • Part 2

Start & Light It Up

lcd.init();
lcd.backlight();

lcd.init();

Initializes the LCD. Put it inside setup().

lcd.backlight();

Turns the backlight ON so the text is visible.

Try the buttons!

Code • Part 3

setCursor(column, row)

lcd.setCursor(4, 1);
  • 1st number = column (0–15)
  • 2nd number = row (0–1)
  • Text starts where the cursor is
Column
Row

Code • Part 4

print() the Text

lcd.print("Hello World!");
  • Prints from the cursor position
  • Text goes in "double quotes"
  • Numbers work too: lcd.print(25);
  • Max 16 characters per row
